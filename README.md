# 青少年阅读时间的机会缺口与试行跟踪

保存本项目的合成资料、资料检查工具与时间机会分析工具。所有人员、学校、机构、
价格和业务记录均为演练数据。

- 资料契约见 [资料契约.md](资料契约.md)，机读字段说明位于 `materials/contract.json`，
  原始记录位于 `materials/data.json`（只读，任何分析都不会回写）。
- 派生解释、学校审核留痕与试行登记写入另行指定的工作目录（默认 `workdir/`，已被忽略）。
- 使用 Python 3.11.2，仅依赖标准库。

## 一、资料检查

```sh
python3 inspect_materials.py
python3 -m unittest discover -s tests -t .
```

## 二、时间机会分析工具 `timeopp`

处理不受信资料时以隔离模式运行，避免资料目录中的同名模块被误导入：

```sh
python3 -I run_tool.py --materials materials --workdir workdir <子命令>
```

全局可选参数：`--json`（完整机读结果）、`--min-valid-days`（默认 7）、
`--min-coverage-ratio`（默认 0.9）。

### 先看清每个人，再进入群体估计

| 子命令 | 作用 |
| --- | --- |
| `inspect` | 资料指纹与各表行数 |
| `coverage` | 每个学生每个本地日的时间轴覆盖、未记录、真实缺口、冲突与争议；`--person` 看个人明细 |
| `disputes` | 只列未解决争议（无法解释的重叠、待审、被拒、审核通过但无法判定） |
| `review` | 登记学校审核决定，留痕到工作目录；不改动原始资料 |

口径要点：

- 区间左闭右开，跨午夜日记按自带时区切到本地自然日。
- 活动字典只声明主次活动的可兼容关系（如做家务时听读）；同步听读单独计量，
  **默认不计入专注阅读**，可用 `estimate --audio-credit` 做敏感性口径。
- 无法解释的重叠保留为争议，重叠分钟不重复占用一天。审核裁决分三种明确情形：
  1. 审核显式指定权威日记行（`review --authoritative-diary-id`）：从另一行扣减；
  2. 两条日记收到日不同：较晚收到的视为事后订正，从较早行扣减，依据留痕；
  3. 收到日相同且未指定权威行：即使审核通过也保留为未解决争议（`approved_unresolved`），
     不猜测自由文本说明。
- 明确的未记录区间（`unknown`）与时间轴上的真实缺口分开报告；
  "昨天读了零分钟"只描述观测，不自动解释成没有空闲。

### 群体估计与适用范围

| 子命令 | 作用 |
| --- | --- |
| `estimate` | 加权阅读量分布（均值、分位数、零阅读日比例）、家庭聚类稳健标准误、未记录导致的有界区间 |
| `gaps` | 完整可用时段、阅读连续性、家庭共同时间、挤压线索；`--person`/`--household` 定向查看 |

口径要点：

- `sample_weight` 只是抽样基础权重；有效回收是另一道关。无日记或覆盖不合格者
  不进入估计，其基础权重只在同一抽样层内、有合格回收时才重新分摊。
- 整层无回收时在 `representability.unsupported_strata` 显式声明该群体不可代表，
  不以零值或极大权重替代；输出有效样本量（ESS）、设计效应与权重极端标记，
  可选 `--trim-weights` 截尾并留痕。
- 未记录与争议分钟不猜成零：给出 `[下界, 上界]` 区间，区间宽度即不可消除的无知。
- 同一家庭两名学生不是独立观测，方差按家庭聚类计算。
- 挤压线索只是零阅读日与有阅读日的活动均值差异，明确标注不可作因果归因。

### 试行方案与效果跟踪

| 子命令 | 作用 |
| --- | --- |
| `pilot-check` | 方案适用性、受益群体与被挤占活动比较、窗口内实际活动观测 |
| `pilot-register` | 登记试行范围与场景（午间校内/课后/晚间） |
| `pilot-status` | 暂停/改换/关闭方案，状态历史完整留痕 |
| `effects` | 试行前后观测比较：星期构成匹配、考试周处理、家庭聚类 SE、归因标注 |
| `trace` | 从群体时间缺口一路追到每个方案的暴露日与观测证据 |
| `revisions` | 日记订正影响：区分可重算的结论与不可改写的已执行安排 |

口径要点：

- 方案带生效日期、覆盖学校、释放时段与被挤占活动；晚间方案默认不适用住校生，
  午间校内方案不得直接套用于走读学生晚间（适用性检查会告警）。
- **计划释放的分钟绝不记成已发生的阅读增长**：`pilot-check` 同时呈现计划分钟
  与窗口内实际阅读；窗口内无阅读时，`effects` 的 DiD 标注为不可归因。
- `confirmed`（已确认未执行）方案不产生暴露日、无效果可评；`executed` 方案即使
  后来暂停或改换，其实际覆盖过的日期仍进入对应解释（状态历史保留）。
- 前后比较按星期匹配并默认排除考试周（`--keep-exam` 可保留）；无合格对照组时
  只报告组内前后差并标注 `uncontrolled_pre_post_only`。
- 日记订正后：诊断缺口、估计与效果说明按新指纹重算；已执行的校内安排不被改写，
  尚未开始（含未登记且未执行）的方案在 `revisions` 中列入复议并给出原因。

## 三、测试

```sh
python3 -m unittest discover -s tests -t .
```

测试覆盖时间区间几何、覆盖与争议三情形裁决、权重与有效回收、有界估计、
家庭聚类方差、机会缺口、方案适用性与 DiD、工作流留痕，以及在小型合成日记上的
命令行端到端链路。小型合成资料由 `timeopp/synth.py` 生成到临时目录，刻意保留
无法判定的情形；正式演练资料 `materials/` 保持不变。
